# Dice Game

Flutter app for the Mobile Development course.

**Student:** محمد مدحت محمد ابراهيم الشربيني
**Task:** Dice Game App

## Description
The player rolls two dice. If the total is 10 or more, a happy image is shown (You Win). Otherwise, a sad image is shown (You Lose). The Reset button returns everything to the initial state.

## Features
- Two dice displayed as icons (custom `Dice` widget)
- Roll and Reset buttons
- Image changes based on the result
- Dark theme

flutter pub get
